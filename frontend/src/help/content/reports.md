# Reports and exports

**Reports** in the sidebar. Six built-in reports, one metrics layer behind all
of them and behind the dashboard, so two surfaces cannot disagree about the same
number.

| Report | Answers |
|---|---|
| **Pipeline by stage** | Where the value sits, raw and probability-weighted. |
| **Funnel conversion** | How many make it from each stage to the next. |
| **Plan adherence by rep** | Planned activities due in the period, and how many landed. |
| **Forecast vs actual** | Month by month, what was forecast against what closed. |
| **Pipeline by segment** | Value by territory, industry or source. |
| **Quota attainment by rep** | Closed-won against target, and the gap. |

## What you can see

Every report is scoped by permission before it aggregates. A rep sees their own
records; a manager sees the reps below them in the sales hierarchy. There is no
report that shows a total you are not allowed to see the rows of.

## Export and print

**Export CSV** takes what is on screen, including the filters you applied.
**Print** produces a clean version — the rail and the buttons drop away, the
table and any notice on the report stay.

## When a report is empty

Some reports say why. **Forecast vs actual** is blank when forecasting itself is
switched off in Settings, because the two fields it needs — expected value and
expected close date — are only mandatory when it is on. Rather than showing an
empty grid beside tiles full of real money, the report says which setting is
responsible, above the table and in the printed copy.

An empty report is not the same as a broken one. Check the period and the
territory filter first.
